# Contributing

This information is for developers who want to contribute to the USWDS Elements project.

## Installing

From the project root, run the following commands:

```bash
npm install
```

### Running StorybookJS

```bash
npm run start
```

---

## Creating stories

Stories should document the following component features:

- Variants (e.g. default, primary, secondary, etc.)
- Properties
- CSS Custom Properties
